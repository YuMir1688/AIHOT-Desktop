## 下载与运行

本版本提供原始文件，不提供压缩包。将以下七个运行文件下载至同一目录：

- AIHOT.Desktop.exe
- AIHOT.Desktop.dll
- AIHOT.Desktop.deps.json
- AIHOT.Desktop.runtimeconfig.json
- AIHOT.Cards.dll
- AIHOT.HotFeed.dll
- QRCoder.dll

新安装需要 Windows x64 与 .NET 10 Desktop Runtime。许可证和第三方说明随版本提供。校验文件见 SHA256SUMS.txt。

已有程序：先退出 AIHOT，并备份原程序目录；用上述 DLL 和 JSON 更新对应文件。保留原 AIHOT.Desktop.exe、runtime 文件夹和个人配置。不需要删除本地缓存、资讯历史或推送状态。

可选开机启动：将 Set-Autostart.ps1、Enable-Autostart.cmd、Disable-Autostart.cmd 放在程序目录，按需启用。
